Integraciones / API para Make

Cómo autenticarse

Todas las llamadas llevan la cabecera X-API-Key: {{ api_key }} (o ?api_key={{ api_key }} en la URL). Base: {{ base }}/api. Respuestas en JSON. Las empresas se identifican siempre por CIF.

En Make usa el módulo HTTP → Make a request, añade la cabecera y, en POST/PATCH, Body type: Raw · Content type: JSON.

Ejemplo: sincronizar el Excel de deudores

Make lee todas las filas del Excel, junta los CIFs (Array aggregator) y hace una sola llamada:

POST {{ base }}/api/deudoras/sincronizar
X-API-Key: {{ api_key }}
Content-Type: application/json

{
  "cifs": ["B12345674", "B98765432"],
  "respetar_manuales": true,
  "simular": false
}

· CIF en la lista y empresa al día → pasa a deudora.
· Empresa deudora que ya no está en la lista → pasa a al día.
· Con respetar_manuales: true, las marcadas a mano por un agente no se tocan.
· Con simular: true te dice qué haría sin cambiar nada (ideal para probar).
· Todo queda en el histórico con el agente Automatización.
